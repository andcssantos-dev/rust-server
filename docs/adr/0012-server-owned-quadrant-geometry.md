# ADR 0012 — Server-Owned Quadrant Geometry

## Status

Accepted for AF2-006B.

## Context

AF2-006A introduced deterministic discovery coordinates through `WorldPositionMm`, `QuadrantCoord`, `QuadrantSizeMm`, and versioned `QuadrantSeed` derivation.

The prototype client can visualize a debug grid, but the client must never choose the authoritative spatial meaning of the universe. In particular, changing the size of a discovery quadrant changes which `QuadrantCoord` contains a given world position and therefore changes the interpretation of an existing universe.

The server configuration already contains legacy `simulation.sector_size_meters`. That field is not redefined as a discovery quadrant. Sector, Quadrant, Zone, AOI cell, streaming cell, and physics cell remain separate concepts unless a future ADR explicitly relates them.

## Decision

### 1. Quadrant size belongs to universe configuration

Add the required server configuration field:

```toml
[universe]
quadrant_size_mm = 512000
```

The unit is explicit millimetres so the value maps exactly to authoritative `WorldPositionMm` without floating-point conversion.

`aurenfall-config` validates that the configured value is positive. The world-server composition root then constructs the strong `QuadrantSizeMm` domain value.

The client does not own this value.

### 2. The current development universe uses 512 m discovery quadrants

The development configuration uses:

```text
512000 mm = 512 m
```

This is the current universe contract, not a client-side rendering preference.

Changing this value for an already-established persistent universe is a world compatibility change and must be treated deliberately.

### 3. Bootstrap terminology moves to Quadrant

The world-server no longer derives its genesis observation through the legacy `sector_seed` API.

Bootstrap derives:

```text
UniverseSeed
+ QuadrantCoord(0, 0)
+ GeneratorVersion
→ genesis QuadrantSeed
```

and logs the authoritative quadrant size and genesis coordinate.

The legacy Sector API remains temporarily available for older code until its remaining semantics are audited; this ADR does not silently redefine Sector to mean Quadrant.

### 4. Geometry is server-owned before it is networked

AF2-006B establishes the authoritative runtime source first.

It intentionally does not yet transmit quadrant geometry or frontier membership to Unreal. That contract belongs to the following frontier/manifest work.

The intended direction is:

```text
server.toml
→ validated Universe configuration
→ QuadrantSizeMm
→ authoritative world runtime
→ future world/frontier manifest
→ UE presentation
```

not:

```text
UE setting
→ authoritative world geometry
```

### 5. V1 seed vectors are frozen

The AF2-006 golden vectors generated by Rust 1.98 are now asserted as exact hexadecimal outputs for the phrase `aurenfall-golden-quadrant-v1`, generator version 1:

```text
(0, 0)
  d86b22078ea1fb12f040eaf9b8dc52f2ae915319cc36b5004a833f24ee1be378

(1, 0)
  2830739b0cec1dde2395de6abbf2ccc494d73beb22a60c795a5632e444bc88bc1

(-1, 0)
  fb2146c6f47527e0e579c5d99e2bf1ba0454559deb6147ed5a29f19cf849f0a3

(123456, -987654)
  299573b2e66f8db63dec33aa2c260af78e8f9f0cdf7a5f541a59956d26c4044
```

A future intentional generator identity change must use a new generator version and/or derivation domain instead of silently changing these V1 outputs.

## Consequences

### Positive

- The authoritative server owns the spatial meaning of the universe.
- Unreal can later receive geometry instead of inventing it.
- Discovery quadrants remain distinct from simulation and streaming partitions.
- The same world coordinates map to the same quadrants across restarts.
- Seed compatibility regressions become immediately test-visible.

### Trade-offs

- `simulation.sector_size_meters` temporarily coexists with `universe.quadrant_size_mm`.
- Existing development tools may still use fallback visual sizes until the world manifest is networked.
- Changing quadrant size requires explicit world-version compatibility handling once durable worlds exist.

## Follow-up

AF2-007 should introduce the server-owned initial frontier and a compact manifest that can communicate which discovery quadrants are revealed/materialized to a client without transferring authority to that client.
